# Telegram Job Hunter — стартовый прототип

## Установка
1. Python 3.11+.
2. `python -m venv .venv` и активируйте окружение.
3. `pip install -r requirements.txt`.
4. Скопируйте `.env.example` в `.env` и впишите токен от BotFather. Не публикуйте `.env`.
5. `python main.py`.
6. В Telegram отправьте боту `/start` и затем `/check`.
7. После получения своего chat_id заполните `ALLOWED_CHAT_ID` в `.env` и перезапустите.

## Важные ограничения
Это MVP, а не окончательная рекомендательная система. Ищет вакансии через публичный API hh.ru с фильтром remote; **не** гарантирует возможность работы из любой страны, зарплату 250–300 тыс. ₽ net или русский рабочий язык. Нет LLM-оценки резюме и международных источников. Не запускайте на публичном сервере с пустым ALLOWED_CHAT_ID после первичной настройки. Возможны дубликаты между ручной проверкой и автоматическим запуском, а также ограничение API. Для production нужны дополнительные источники, строгая проверка локации, зарплат, дедупликация и мониторинг.
